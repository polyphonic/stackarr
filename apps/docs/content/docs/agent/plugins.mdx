# Agent Plugins

Stackarr ships local plugin bundles that point agents at the same MCP server:

- `packages/agent-plugins/hermes/stackarr`
- `packages/agent-plugins/openclaw/stackarr`
- `skills/stackarr/SKILL.md`

The integrations all launch the same local MCP command:

```bash
stackarr mcp serve
```

## Preferred Install

Use Stackarr's plugin installer when available:

```bash
stackarr plugins install hermes --profile manage
stackarr plugins install openclaw --profile manage
```

Hermes is configured through its native MCP client so its approval UI and per-tool schemas remain intact. OpenClaw receives a direct MCP bundle. Docker installs generate a host-side `docker exec -i` command.

## Manual MCP Config

Any MCP-capable client can use the server directly:

```json
{
  "mcpServers": {
    "stackarr": {
      "command": "stackarr",
      "args": ["mcp", "serve"],
      "env": { "STACKARR_MCP_PROFILE": "manage" },
      "timeout": 120,
      "connect_timeout": 30
    }
  }
}
```

## What Agents Can Do

Agents can:

- read setup defaults and run setup dry-runs
- start, stop, and inspect managed services
- run backups and read backup progress
- inspect disk usage and service health
- manage Cloudflare routes when configured
- troubleshoot download clients, indexers, Plex, and Arr services

Destructive or disruptive tools pause for a client-mediated approval prompt in `manage` and `admin`. Unsupported clients fail closed. The user can choose `unrestricted` at launch when complete autonomous control is desired.

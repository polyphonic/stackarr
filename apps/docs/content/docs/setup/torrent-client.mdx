# Torrent Client

Stackarr supports Transmission and qBittorrent, with one active client at a time.

Choose the preferred client in setup or Settings. The selected client profile is included when the stack starts. The inactive client can be removed so ports and state do not conflict.

Download presets map categories for Radarr, Radarr 4K, Sonarr, Sonarr 4K, and related imports.

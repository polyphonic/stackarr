# Configure your stack

You can complete setup from chat or in the browser. Both paths use the same validation, save the same settings, and show the same final plan.

## Recommended: set up from chat

Connect an agent with the `admin` profile and ask:

> Set up Stackarr for me. Recommend safe defaults, ask only about choices that materially change the stack, and show a dry-run before applying anything.

See [Agent Setup](/docs/agent/agent-setup) for the connection command and review checklist.

## Set up in the browser

Open [http://127.0.0.1:7777/setup](http://127.0.0.1:7777/setup) and choose:

1. fresh setup, restore, or migration
2. media, download, and backup folders
3. Plex, Jellyfin, and content categories
4. Transmission or qBittorrent
5. optional request, subtitle, metadata, photo, game, and book apps
6. authentication and local or remote access
7. backup and update preferences
8. quality and naming presets

The review screen shows the containers, paths, ports, and saved settings before anything is applied.

## After setup

- verify service health from chat or the dashboard
- change an agent from `admin` to `manage`
- reconnect the MCP client so it loads actions for the selected apps
- run the first backup before making major changes

# Network Access

Default to private local access. Stackarr binds the dashboard locally on port `7777` unless changed in Settings or advanced Docker configuration.

Only expose Stackarr after configuring:

- General authentication.
- API key.
- Public URL.
- Cloudflare or reverse proxy route.

Seerr public access is separate from Stackarr public access. Configure each intentionally.

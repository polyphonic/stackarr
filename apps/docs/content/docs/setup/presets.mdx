# Presets

Stackarr keeps preset files in `stackarr/config`.

| Preset | Purpose |
| --- | --- |
| `naming.json` | Plex-friendly Radarr/Sonarr and TinyMediaManager naming. |
| `downloads.json` | Download-client categories and import defaults. |
| `requests.json` | Seerr request defaults for HD and 4K flows. |

The dashboard stores active choices in Stackarr's database while keeping preset files readable and portable with the rest of your configuration.

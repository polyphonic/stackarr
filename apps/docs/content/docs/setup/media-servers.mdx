# Plex and Jellyfin

Choose Plex, Jellyfin, both, or neither.

- **Managed container:** Stackarr starts and manages the media server inside the Compose stack.
- **Existing server:** Stackarr connects to a media server already running outside its Compose project. Stackarr can monitor and configure the integration but does not own that process.
- **Disabled:** Stackarr ignores that media server and removes its agent actions.

Managed containers are the simplest path for a new installation. Use an existing server when you are preserving an established library or hardware-transcoding setup.

Keep an existing server reachable only from trusted local networks and enter its URL and token through Stackarr's authenticated settings.

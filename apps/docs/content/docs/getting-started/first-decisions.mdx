# First Decisions

## Plex and Jellyfin

Each media server has its own install mode:

- **Native:** use the existing macOS app and data.
- **Docker:** run the media server inside Stackarr's compose group.
- **Disabled:** Stackarr ignores that media server.

Use `native` when hardware transcoding and existing macOS app data should stay outside Docker. Use `docker` when the media server should be part of the compose group.

## Torrent Client

Choose one active torrent client in setup or Settings:

- Transmission
- qBittorrent

Stackarr starts only the selected profile and can remove the inactive client container.

## Public Access

Do not expose the dashboard first. Configure:

- General authentication.
- API key.
- Public URL.
- Cloudflare tunnel or reverse proxy.

Then publish the route intentionally.

## Agent Mode

Agent setup should always dry-run first. The agent should ask only for material decisions: paths, torrent client, Plex mode, Jellyfin mode, and whether to apply setup now.

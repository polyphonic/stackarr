# Getting Started

Stackarr is an agent-ready control plane for a private home media server. It brings your media server, request app, download client, library managers, backups, and optional remote access behind one consistent action layer that works from chat, the dashboard, the API, or the CLI.

## What It Helps With

- **Agent-guided setup:** let a trusted agent inspect defaults, prepare a dry-run, and apply the setup after your approval.
- **Consistent actions:** chat clients and the optional dashboard use the same typed operations and native app APIs.
- **Private defaults:** the dashboard starts on localhost and stays private until you choose another access mode.
- **Mac-friendly media servers:** native Plex on macOS is supported, with Docker-compatible services around it.
- **Consistent folders and naming:** presets keep downloads, imports, and renaming aligned across the stack.
- **Recoverable installs:** backup and restore settings are part of the normal setup path.

## Typical Flow

1. Install Stackarr through Docker or macOS source/app archive.
2. [Connect an agent](/docs/agent/agent-setup) with the `manage` profile, or open `http://127.0.0.1:7777/setup` to work manually.
3. Ask the agent to inspect the setup profile and show a dry-run before applying anything.
4. Choose storage paths, media-server modes, and Transmission or qBittorrent when prompted.
5. Keep network exposure private until authentication is configured.
6. Approve the plan, then verify service health from chat or the dashboard.
7. Use the Agent Activity view to review what ran and intervene whenever needed.

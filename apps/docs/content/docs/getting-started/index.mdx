# Getting Started

Stackarr is the setup and maintenance app for a private home media server. It brings your media server, request app, download client, library managers, backups, and optional remote access into one place.

## What It Helps With

- **Guided setup:** choose storage, media-server mode, torrent client, requests, books, and backups.
- **Private defaults:** the dashboard starts on localhost and stays private until you choose another access mode.
- **Mac-friendly media servers:** native Plex on macOS is supported, with Docker-compatible services around it.
- **Consistent folders and naming:** presets keep downloads, imports, and renaming aligned across the stack.
- **Recoverable installs:** backup and restore settings are part of the normal setup path.

## Typical Flow

1. Install Stackarr through Docker or macOS source/app archive.
2. Open `http://127.0.0.1:7777/setup`.
3. Choose storage paths and media-server modes.
4. Choose Transmission or qBittorrent.
5. Keep network exposure private until auth is configured.
6. Save the setup and queue stack configuration when ready.
7. Use Dashboard, Settings, System, Connect, and Agent views for day-to-day work.

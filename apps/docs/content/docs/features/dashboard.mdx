# Dashboard

The Dashboard is the operational home for the stack.

## What It Shows

- Running/stopped service counts.
- Service health summaries.
- Performance charts for stack/server metrics.
- Service map with real SVG logos for Sonarr, Radarr, Prowlarr, Bazarr, Plex, Jellyfin, Seerr, Transmission, qBittorrent, TinyMediaManager, Recyclarr, and Cloudflare.
- Quick access to setup, stack views, settings, system status, and agent activity.

## Intended Use

Use Dashboard for daily scanning. Use Stack pages for service-specific details, Settings for configuration, and System for logs/tasks/backups/updates.

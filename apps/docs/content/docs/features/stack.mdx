# Stack

Stack pages show the services that Stackarr can monitor or configure.

## Services

The services view shows status, ports, management mode, and the actions available for each enabled app.

## Commands

Commands are queued as tasks, not run inline. Examples:

- `StackStart`
- `StackStop`
- `StackConfigure`
- `ApplyNamingPreset`
- `ApplyDownloadsPreset`
- `ApplyRequestsPreset`
- `Backup`
- `Update`
- `PlexCheck`
- `PermissionsAudit`

Chat, dashboard, and API actions enter the same task queue, so progress and results stay visible whichever surface you use.

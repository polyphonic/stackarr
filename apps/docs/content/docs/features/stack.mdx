# Stack

Stack pages show the services that Stackarr can monitor or configure.

## Services

The services view focuses on the compose/app surface: status, ports, install mode, and queueable actions.

## Commands

Commands are queued as tasks, not run inline. Examples:

- `StackStart`
- `StackStop`
- `StackConfigure`
- `ApplyNamingPreset`
- `ApplyDownloadsPreset`
- `ApplyRequestsPreset`
- `Backup`
- `Update`
- `PlexCheck`
- `PermissionsAudit`

The UI and API share the same command registry from `packages/core`.

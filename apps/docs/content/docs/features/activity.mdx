# Activity

Activity shows current work, completed tasks, agent actions, routines, and server logs in one place.

## Queue

Shows current and pending Stackarr tasks.

## History

Shows completed command/task records.

## Agent and routine trail

Calls made from chat and the Stackarr app record their caller, operation, status, duration, and redacted input/result summary. Scheduled routines appear in the same trail.

## Server logs

Open **Activity → Server logs** to inspect recent output without opening a terminal. Stackarr confines reads to `.log` files in its configured log directory, returns at most 500 lines from a bounded 256 KB tail, and redacts tokens, authorization values, URL passwords, cookies, and common secret assignments before they reach the browser.

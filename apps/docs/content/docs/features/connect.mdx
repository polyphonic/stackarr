# Connect Workflow

Connect is for explicit integrations where Stackarr talks to another app API or webhook endpoint.

It is not a list of every service in the stack.

## Current Connect Types

- Cloudflare tunnel and public URL routing.
- Seerr public URL/request routing integration.
- TinyMediaManager naming alignment.
- Generic webhooks.

## Events

- `Test`
- `Health`
- `HealthRestored`
- `StackStart`
- `StackStop`
- `Configure`
- `Backup`
- `Update`
- `ServiceStateChange`
- `SetupComplete`

# Media Servers View

The Media Servers view summarizes Plex and Jellyfin independently.

## Native Mode

Native mode reports the configured path, detected state, and guidance for monitoring/config features. Stackarr does not own the process.

## Docker Mode

Docker mode reports the compose profile and service state. Stackarr starts only selected media-server profiles.

## Why This Matters

Hardware transcoding is often easier to keep correct with native macOS media-server installs. Stackarr is designed to work with that instead of forcing everything into Docker.

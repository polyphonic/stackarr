# Media servers

The Media Servers view shows Plex and Jellyfin independently, including connection state, management mode, and the actions Stackarr can safely perform.

## Managed container

Stackarr owns the matching Compose service, health checks, and lifecycle actions.

## Existing server

Stackarr connects to a server outside its Compose project. This preserves an established library or hardware setup while still making status, libraries, sessions, and supported maintenance actions available to the dashboard and agents.

## Why the distinction matters

Stackarr only offers restart and container lifecycle actions for services it owns. Existing servers remain under your manual process control.

# Profiles and Presets

Profiles and Presets is where you choose Stackarr's quality and naming behavior.

## Naming

Naming presets align Radarr, Sonarr, and TinyMediaManager with Plex-friendly file names.

## Downloads

Download presets define categories and import behavior for HD and 4K Radarr/Sonarr flows.

## Requests

Request presets wire Seerr defaults to the correct Radarr/Sonarr instances and profiles.

The saved preset files remain in `.stackarr/config` so they are portable and easy to review.

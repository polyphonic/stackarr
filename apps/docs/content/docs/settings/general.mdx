# General

General contains host-level settings.

| Setting | Notes |
| --- | --- |
| Bind address | Keep `127.0.0.1` until ready to expose. |
| Port | Defaults to `7777`. |
| URL base | Use only when reverse proxying under a path. |
| Public URL | Used by public exposure and webhook payloads. |
| Authentication | Controls local dashboard auth behavior. |
| API key | Used by authenticated `/api/v1` requests. |

Secrets are redacted before they are shown in the browser.

# Settings

Global Settings contains only choices shared by the homelab. Open **Apps**, choose an app, and use its **Settings** button for that app's connection, credentials, container options, and optional Cloudflare route.

## Sections

| Section | Purpose |
| --- | --- |
| Media Management | Shared storage roots and backup schedule. |
| Profiles | Defaults shared by related media apps, including HD and 4K profiles. |
| Connect | Cloudflare tunnel, shared webhooks, and public access. |
| Account | Stackarr sign-in, owner identity, and API access. |
| General | Timezone, update windows, and Stackarr paths. |
| UI | Theme, density, time format, dashboard presentation. |

App-specific passwords and isolated database credentials are no longer duplicated in global Settings. They remain protected and are edited from the owning app's HeroUI settings panel.

# Settings

Stackarr follows the arr settings shape: focused sections, advanced details where they belong, and explicit Connect integrations.

## Sections

| Section | Purpose |
| --- | --- |
| Media Management | Storage roots and ownership assumptions. |
| Profiles and Presets | Naming, downloads, request defaults, HD/4K presets. |
| Download Clients | Transmission/qBittorrent selection and port/bind defaults. |
| Indexers | Prowlarr and indexer sync status. |
| Connect | API integrations and webhooks. |
| Metadata | Media-server metadata and naming guidance. |
| General | Host, auth, API key, URL base, public URL. |
| UI | Theme, density, time format, dashboard presentation. |

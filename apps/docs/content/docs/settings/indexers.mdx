# Indexers

Indexer configuration centers on Prowlarr.

Stackarr can configure Prowlarr application links for Radarr, Sonarr, and Lidarr, and can seed default indexers where definitions are available.

Keep custom indexer scoping on indexers or proxies rather than on Stackarr-managed Prowlarr application records unless you intend to manage sync manually.

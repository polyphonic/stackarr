# Docker Hub

Stackarr publishes alpha images to:

```text
polyphonic/stackarr
```

## Personal Account Repository Presentation

Docker Hub repository pages expose:

- Repository description.
- Repository overview/README.
- Categories.
- Tags.

Docker Hub's public docs say the repository overview is edited from the Hub UI, and automated builds can sync it from the source repository README.

## Repository Logo

Dockerfile labels and files inside the image do not set the Docker Hub page logo. For personal accounts, the visible page icon generally comes from the Docker Hub namespace/account avatar, or the default cube when no applicable avatar/logo is configured.

Docker documents per-repository logo upload for Docker-Sponsored Open Source organizations. If Stackarr becomes eligible for DSOS, upload `Logo/stackarr-512.png` as the repository logo.

## Recommended Action

1. Set the Docker Hub account or organization avatar to the Stackarr logo.
2. Edit the repository overview and put the logo at the top:

```md
<p align="center">
  <img src="https://raw.githubusercontent.com/b-bot/stackarr/main/Logo/stackarr-512.png" width="120" alt="Stackarr logo" />
</p>
```

3. Keep OCI labels in the image for tools that read them.
4. Apply for Docker-Sponsored Open Source if a per-repository logo is required.

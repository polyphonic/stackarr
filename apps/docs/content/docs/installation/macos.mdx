# macOS Install

Use macOS when Plex or Jellyfin already run natively and you want Stackarr to monitor and configure the rest of the stack around them.

## Source Install

```bash
git clone https://github.com/b-bot/Stackarr.git
cd Stackarr
corepack enable
pnpm install
pnpm build
STACKARR_WEB_PORT=7777 pnpm dev
```

Open:

```text
http://127.0.0.1:7777/setup
```

## App Archives

Alpha macOS archives are generated separately for Apple Silicon and Intel:

```bash
pnpm package:macos
```

The package script builds the Next.js standalone frontend and wraps it in a macOS app archive.
Extract the matching archive, then move `Stackarr.app` to `/Applications`.

Opening `Stackarr.app` opens the dashboard in your browser. If the dashboard is already running, the app uses the existing server; otherwise it starts the bundled local server first:

```text
http://127.0.0.1:7777
```

App archives include a `stackarr` helper next to `Stackarr.app` for Terminal tasks that need a password prompt, such as Portless:

```bash
./stackarr portless install
```

If `Stackarr.app` has been moved to Applications without the helper, use the bundled command directly:

```bash
/Applications/Stackarr.app/Contents/MacOS/Stackarr portless install
```

For native startup, update, backup, and tunnel background jobs, run install commands from the app-bundled helper after moving the app to Applications:

```bash
/Applications/Stackarr.app/Contents/MacOS/Stackarr startup install
/Applications/Stackarr.app/Contents/MacOS/Stackarr backup install
/Applications/Stackarr.app/Contents/MacOS/Stackarr update install
```

Those LaunchAgents are associated with the `Stackarr.app` bundle in macOS Login Items and Background Activity. If the backup root lives on an external drive, grant the needed file access to `Stackarr.app`.

Docker installs do not need a shell privacy exception. Choose media, downloads, and backup folders during setup, share those folders with Docker Desktop or OrbStack, then run **System > Status > Audit permissions** so Stackarr checks the actual bind mounts.

Alpha builds are ad-hoc signed for local testing. Public release builds should be signed with a Developer ID certificate and notarized so macOS shows Stackarr as an identified developer app.

## Native Media Servers

Choose `native` during setup when Plex or Jellyfin already exists on the Mac. Stackarr will not move media-server data unless you explicitly choose a Docker install mode.

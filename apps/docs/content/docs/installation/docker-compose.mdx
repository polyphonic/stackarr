# Compose Service

To run Stackarr inside the managed compose project, use the compose defaults or override only the Stackarr service bootstrap values when needed:

```dotenv
STACKARR_WEB_ENABLED=true
STACKARR_IMAGE=polyphonic/stackarr:alpha
STACKARR_BIND_IP=127.0.0.1
STACKARR_WEB_PORT=7777
```

Start only the Stackarr service:

```bash
docker compose -f stackarr/docker-compose.yml --profile stackarr up -d app
```

Developers working from a local checkout can override `STACKARR_IMAGE=stackarr:local` after building that tag.

## Update the Running Service

```bash
docker compose -f stackarr/docker-compose.yml --profile stackarr pull app
docker compose -f stackarr/docker-compose.yml --profile stackarr up -d app
```

This recreates only the Stackarr dashboard/API container unless other services are explicitly included.

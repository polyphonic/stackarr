# Windows Install

Windows native packaging is available for alpha testing, but Docker remains the supported Windows backend for stack actions while the native runner is completed.

Windows packages are untested alpha artifacts. They are provided so Windows testers can validate the dashboard launcher and installer project while the Docker/bash-backed stack runner is replaced or wrapped for native Windows behavior.

## Build

```bash
pnpm package:windows
```

The package contains a `Stackarr` app payload and an Inno Setup project:

```text
distribution/windows/dist
```

On a Windows builder with Inno Setup 6 installed:

```bat
cd setup
build.bat
```

The installer writes application files to:

```text
C:\ProgramData\Stackarr\bin
```

The dashboard stores user runtime data under `%LOCALAPPDATA%\Stackarr` unless `STACKARR_DATA_DIR` is set.

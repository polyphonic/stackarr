# Documentation Site

The public documentation site is a single Fumadocs-based Next.js app that serves both the landing page and docs.

```bash
pnpm --filter @stackarr/docs build
pnpm dev:docs
```

Use for Vercel or other hosting. The Stackarr Docker image and macOS package do **not** include the docs app — they focus on the local runtime (frontend + stack control).

Set the deployment URL so canonical links, Open Graph metadata, `robots.txt`, `sitemap.xml`, and structured data point at the public site:

```bash
NEXT_PUBLIC_SITE_URL=https://your-stackarr-docs-domain.example
NEXT_PUBLIC_GITHUB_URL=https://github.com/b-bot/Stackarr
```

See root README and install.md for full distribution notes.

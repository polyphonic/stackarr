# Comparison to Arr Apps

Sonarr, Radarr, Lidarr, and related apps are mainly C#/.NET because they are long-running backend applications with a mature cross-platform runtime, strong SQLite support, and years of packaging across Windows, Linux, macOS, BSD, Docker, and NAS systems.

Stackarr using Next.js is not automatically prohibitive for NAS use. Node and Docker run well on modern NAS devices. The practical constraints are image size, memory, native module portability, filesystem permissions, and Docker socket access.

Stackarr copies the useful arr conventions:

- Fixed local port.
- Browser UI.
- `/api/v1`.
- `X-Api-Key`.
- Queued commands.
- System/Settings/Activity/Connect sections.
- SQLite app settings.
- Logs, backups, health, disk space, and update views.

It does not copy media-library domain logic that is unrelated to managing the stack.

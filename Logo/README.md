# Stackarr Logo

Stackarr keeps its brand assets in a root `Logo/` directory, matching the convention used by the arr-family repositories.

- `stackarr.svg` is the source vector mark.
- `stackarr-512.png` is the Docker, PWA, and app-store style raster mark.

The Docker image also exposes the public PNG URL through OCI labels so registry and desktop tools have a stable icon hint once the repository is public.
